# Coverage Report

## Overview

Generate a test coverage report. Use make commands.

## Steps

1. **Run coverage**
   - Run `make test-cov`

2. **Summarize**
   - Report overall percentages: lines, branches, functions
   - Flag files with low coverage

3. **Suggest tests**
   - Recommend specific tests for low-coverage areas

## Checklist

- [ ] make test-cov completed
- [ ] Summary with percentages provided
- [ ] Low-coverage areas flagged
- [ ] Suggestions for new tests provided
